## Functions of Random Variables

### Task [11.2024]

Let $X \sim U(1,4)$. Determine the probability density function of $Y=(X+3)^2$.

### Task [11.2024]

Let $X \sim U(6,10)$. Determine the probability density function of $Y=(X-4)^2$.

### Task [11.2021]

Let $X \sim \mathcal{E}(3)$. Determine the probability density function of $Y=|X+1|$.

### Task [2020/21]

Let $X \sim U(-1,1)$. Determine the probability density function of $Y=(X-1)^2$.

### Task [11.2023]

Let $X \sim \mathcal{E}(3)$. Determine the probability density function of $Y=X^2+3$.

### Task [11.2022]

The random variable $X$ has the density

$$
p(x) =
\begin{cases}
\frac{x+1}{2}, & -1 < x < 1,\\
0, & \text{otherwise}.
\end{cases}
$$
